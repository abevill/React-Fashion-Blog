# React Fashion Blog

## ALAB 320H.1.2 – React Fashion Blog

### Overview

This project recreates a Fashion Blog website first using **HTML and CSS**, then rebuilds the same design using **React**. The goal is to practice semantic HTML, responsive CSS styling, React component architecture, and deployment using GitHub Pages and Netlify.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/react-fashion-blog.git
```

Navigate into the project:

```bash
cd react-fashion-blog
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Build for production:

```bash
npm run build
```
